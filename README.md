---

## 它解决什么问题

告警只是一个有上限的内存数组，没有规则、分级、去重与确认，却已有导航入口与报告指标。

## 做 / 不做

| 做 | 不做 |
|---|---|
| 规则注册与求值（阈值 / 持续 / 组合 / 恢复） | 不内建任何业务规则 |
| 产生与分级 | 不做推送（出口为反向接口） |
| 去重合并、抖动抑制、升级、风暴保护 | 不做界面浮层与列表 |
| 父子抑制关系 | 不做通知渠道 |
| 确认 / 关闭 / 重开 / 消音与留痕 |  |
| 台账查询与订阅式分发 |  |
